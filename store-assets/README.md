# Store Assets

Use this folder for browser store listing assets that are not bundled into the extension.

- `screenshots/`: Chrome Web Store and Firefox AMO screenshots.
- `icons/`: Optional store-only icons or promotional images.
- `listing-copy/`: Optional drafts or alternate listing text.

Do not put private ChatGPT conversations or personal data in screenshots.

Chrome Web Store screenshots must be exported as `1280x800` or `640x400`
PNG/JPEG images. Firefox AMO recommends `1280x800`, or another `1.6:1`
image if needed.
